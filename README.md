# React App Setup with Vite

## Prerequisites

Before you start, ensure you have the following installed:

- **Node.js** (Latest LTS version recommended)
- **npm** (Comes with Node.js)

### Install Node.js

Download and install Node.js from the official website:

- [Node.js Official Website](https://nodejs.org/)

After installation, verify Node.js and npm versions:

```sh
node -v
npm -v
```

### Install npm (if not found)

If `npm` is not installed or not found, install it manually by running:

```sh
npm install -g npm
```

Verify the installation again:

```sh
npm -v
```

## Setting Up a React App Using Vite

Vite is a fast build tool for modern web applications.

- [Vite Official Website](https://vitejs.dev/)
- [Vite Guide](https://vitejs.dev/guide/)

### Step 1: Create a New React Project

Run the following command to create a new React project using Vite:

```sh
npm create vite@latest
```

Follow the prompts to:
1. Enter your project name (e.g., `my-react-app`)
2. Select `React` as the framework
3. Choose `JavaScript` as the variant

### Step 2: Navigate to the Project Directory

```sh
cd my-react-app
```

### Step 3: Install Dependencies

```sh
npm install
```

### Step 4: Start the Development Server

Run the following command to start the development server:

```sh
npm run dev
```

### Step 5: Open in Browser

Once the server is running, open your browser and go to:

```
http://localhost:5173/
```

## Conclusion

You have successfully set up a React application using Vite! Happy coding! 🎉
